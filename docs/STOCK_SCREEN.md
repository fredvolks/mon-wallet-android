# US/Canada research screen

The Analyst Ideas page queries actual TradingView primary stock listings on NASDAQ, NYSE, AMEX, TSX, TSXV, CSE and NEO. Provider counts must match the complete response; an unavailable/partial response never falls back to a curated catalogue. This public endpoint has no guaranteed availability or freshness SLA.

Hard exclusions precede selection: OTC/other exchanges, invalid or sub-1 listing-currency prices, non-CAD/USD quotes, Biotechnology, Pharmaceuticals: Major and Investment Trusts/Mutual Funds. Company classifications remain provider evidence, not an independent business audit. No market-cap ceiling/floor and no budget-affordability gate.

The default financial gate requires seven finite metrics, positive trailing P/E/ROE/net margin and nonnegative debt/equity. None disables these financial gates but preserves hard exclusions. Sector-relative midrank percentiles use revenue/EPS growth 12.5 points each, ROE 15, net margin 5, debt 20, P/E 20, six-month return 15. Lower debt/positive P/E are preferred; negative P/E and negative equity do not earn valuation/debt points. Groups under five use the overall eligible universe. Incomplete metrics produce no score. This exploratory heuristic is not a calibrated return forecast.

At most 200 candidates are retained. The UI renders pages of 20 and calculates whole shares/cost afterwards; unaffordable candidates remain visible. Quotes are clearly labelled as possibly delayed observations without verified exchange timestamp. The scan snapshot and AI opinions are stored with the existing owner-scoped research cache.

The explicit Analyze action sends public snapshot evidence plus budget/horizon/risk to `analyze-stock-screen` in deterministic groups of 20. It does not send family names, emails, transactions or account IDs. Model selection and output budget are server-controlled (`OPENAI_SCREEN_MODEL`, default `gpt-6-luna`, `OPENAI_API_KEY` stays server-side). Research priority is a subjective 0–100 score, never a probability or order. This endpoint has no web tools: it cannot claim to verify news or normalize issuer filings. The separate per-title research page remains available for more detailed evidence.

The handler verifies a real non-anonymous Auth user before accessing service-only RPCs. SHA-256 includes version/model/input; private cache leases prevent simultaneous duplicate groups, completed results survive a lost client response, and only a matching lease can finalize. Shared investment quota: at most 20 newly claimed requests/day (a full 200 uses 10 groups). Failed upstream calls consume an attempt; cached calls do not. Partial client results persist after each group; resumed runs skip completed groups. Full AI ordering appears only when every retained candidate has a validated opinion; otherwise the screen order stays quantitative. No automatic paid monthly execution is installed. Snapshots older than 31 days require refreshing.

Validation: backend Node tests plus Deno typecheck; JVM/Android parser boundaries and completeness; real bulk scan on an Android emulator; Room/auth/lease/quota tests via rolled-back SQL. A successful paid model response still depends on configured model access, provider availability and API credit balance. Unavailable credits must surface a clear error and never synthesize opinions.
